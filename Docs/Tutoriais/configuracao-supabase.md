# Tutorial: Instalando e Conectando o Supabase no React

Este guia passo a passo ensina como instalar a dependência oficial do Supabase, centralizar a conexão em um arquivo de configuração e realizar a primeira chamada de dados em uma tela React.

## Passo 1: Instalar o SDK do Supabase
Abra o terminal na raiz do projeto e instale o cliente oficial do Supabase executando o comando:

```bash
npm install @supabase/supabase-js
