# Como adicionar um novo produto

## 1. Abrir o arquivo de produtos

Abra o arquivo onde os produtos estão cadastrados.

---

## 2. Adicionar um novo objeto

Exemplo:

```js
{
  nome: "Hambúrguer",
  preco: "R$ 25,00",
  imagem: "url-da-imagem"
}
```

---

## 3. Salvar o projeto

Após salvar, o produto aparecerá automaticamente na tela inicial.
