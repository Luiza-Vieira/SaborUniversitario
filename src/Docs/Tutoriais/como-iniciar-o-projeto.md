# Como iniciar o projeto

## 1. Instalar as dependências

Abra o terminal dentro da pasta do projeto e execute:

```bash
npm install
```

---

## 2. Rodar o projeto

Execute:

```bash
npm run dev
```

---

## 3. Abrir no navegador

Acesse:

```text
http://localhost:5173
```

---

## 4. Estrutura principal

O projeto utiliza:

* React
* React Router DOM
* CSS puro
* LocalStorage

---

## 5. Páginas principais

* Home
* Carrinho
* Resumo do Pedido
* Pedido Feito
* Meus Pedidos
